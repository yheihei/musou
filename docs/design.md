# 設計メモ

musou の遊びと作り方の決定事項をまとめる。
用語の定義は [CONTEXT.md](../CONTEXT.md)、後から変えにくい判断の理由は [docs/adr/](adr/) にある。
数値は目安で、実際の値は `src/shared/Config.luau` に置いて調整する。

## 概要

- CryptoNinja のキャラクターで遊ぶ、真・三國無双6ライクな協力アクション
- 戦場の仕組みと秘計は、真・三國無双6 Empires の「絶招秘計」と戦場ルールに寄せる
- 最大4人の協力プレイ。ソロでも遊べる
- 主な操作環境は PC とゲームパッド。スマホ横画面は M2 で対応する
- CryptoNinja 公式とは関係のない非公式ファンゲーム。ロビーに非公式である旨を表示する

## 世界観と物語

- 舞台は戦乱の時代のクラン抗争。現代のキャラクターも登場するパラレル設定（[ADR 0001](adr/0001-setting-warring-era-clan-war.md)）
- ストーリーはクランごとに1本。ステージをクリアすると次のステージが開放される
- M1 は伊賀のストーリー第1ステージ。相手は風魔。味方軍の首領はハヤテ（NPC）
- あらすじと台詞は Claude が下書きし、開発者が直す
- キャラクター設定は NINJAMCP を正とする

### イベントシーン

- ステージの前後は、ゲーム内の寸劇で見せる。カメラワーク、簡単なモーション、顔グラフィック付きの会話窓
- 戦闘中は、動きを止めずに顔グラフィックと台詞を画面端に出す
- ボイスはなし
- パーティー全員で同時に見る。全員がスキップを押すと飛ばす（「スキップ 2/4」を表示）
- スキップは押したら取り消せない。再生中は移動と攻撃を止め、HUD を隠す
- M1 では開始・戦闘中・終了の3種を1本ずつ作る

### 顔グラフィック

- NINJAMCP のキャラクター画像を Codex に読ませて作る
- 表情差分（通常・怒り・驚き・喜び・苦悶）を作り、少し可愛い方向にアレンジする

## 協力プレイと進行

- 1つのプレースにロビーと全ステージを置き、1サーバーを1パーティーとして扱う（[ADR 0002](adr/0002-single-place-lobby-and-stages.md)）
- 途中参加はなし。出撃中にサーバーへ入ったプレイヤーは、ステージが終わるまでロビーで待つ
- 知らない人とも同じパーティーになる。身内だけで遊びたい人向けにプライベートサーバーを M3 で用意する
- リーダーはサーバーに一番早く入ったプレイヤー。抜けたら次に古いプレイヤーへ移る
- 進行はプレイヤーごとに保存する。挑戦できるのはリーダーが開放済みのステージ
- リーダーがストーリーを選び、そのストーリーのステージから挑むステージを選ぶ
- 選べるストーリーは、リーダーが開放したステージのあるものだけ。ステージがまだ無いストーリーは準備中と出す
- 各ストーリーの第1ステージは、最初から全員に開放している
- クリアすると、参加者全員にそのステージと次のステージが開放される
- 進行の保存データの形は M1 から変えない。M1 の進行はそのまま引き継ぐ

### キャラクター選択

- 選べるのは、リーダーが選んだストーリーのクランに属するキャラクターだけ
- パーティー内で同じキャラクターは選べない
- そのステージに NPC として登場するキャラクターは選べない
- 首領は常に NPC。プレイヤーは首領にならない

### 人数による調整

- 敵の上忍と首領の体力を、パーティーの人数に応じて上げる
- 兵力もパーティーの人数に応じて増やす
- 難易度は M1 では「普通」の1つだけ
- 人数は出撃したときのメンバーの数で決める。途中で抜けても、そのステージの間は体力と兵力を変えない
- 味方軍の上忍と首領の体力は人数で変えない
- 倍率は人数ごとの表で `Config.luau` に置き、1人のときを 1 とする

## 戦場

- 1ステージは30分程度。制限時間は40分から調整する
- M1 の戦場は拠点5〜7個の小さなもの
- 拠点・部隊・上忍・首領の配置は、位置をプレースの目印、構成をコードに分けて持つ（[ADR 0006](adr/0006-positions-as-markers-composition-in-code.md)）

### 拠点・兵站線・支配エリア

- 拠点は耐久を持ち、中にいる敵を倒すと耐久が減る。0になると制圧される
- 耐久が減るのは、範囲の中でその拠点の軍の下忍が倒れたとき。プレイヤーの撃破でも、部隊どうしの交戦の損害でも減る
- 制圧すると、範囲の中にいた元の軍の部隊は敗走して消える。制圧した直後の耐久は上限の半分から始まる
- 制圧は拠点の陥落の出来事として士気を動かす。得をするのは制圧した軍
- 守備は、範囲の中にいるその拠点の軍の部隊。耐久が残る間、上限まで一定の間隔で補充する
- 補充を受けるのは、配置で方針が防衛のその拠点の部隊。いなければ拠点に守備の部隊を作る
- 守備のいない拠点は、攻める軍が範囲の中にいる間、少しずつ耐久が減る
- 攻める軍は相手の軍の部隊。敵軍の拠点では、出撃したプレイヤーも数える
- 拠点の種類は通常拠点と本陣。秘計で兵糧庫に改築できる
- 本陣から味方の拠点を順につないだ線が兵站線。切られた先の拠点は孤立する
- 兵站線は、拠点の制圧と、つながりを通れなくしたときと戻したときに求め直す
- 落石で塞いだつながりは、使った軍の相手の軍だけが通れない
- 孤立した拠点は守備を補充しない。兵站線がつながると補充を再開する
- 兵糧庫に改築した拠点は兵站線が切れても孤立しないが、その先へは兵站線を延ばさない。制圧されると兵糧庫ではなくなる
- 兵站線でつながった拠点の周りが支配エリア。支配エリアの中では、その軍の部隊と上忍の能力が上がる
- 支配エリアは、兵站線につながった拠点の中心から一定の半径の円。孤立した拠点は支配エリアを持たない（兵糧庫は孤立しないので持つ）
- 2つの拠点の支配エリアが重なる地点は、中心が近い拠点の軍のもの
- 支配エリアの中では、部隊は交戦の押す力が上がり、上忍と首領は攻撃と防御が上がる。首領は本陣にいるので、本陣が兵站線の起点である限り上がったまま

### 勝敗

- 勝利は、敵軍の首領の撃破か、敵軍の本陣の制圧
- 敗北は、味方軍の本陣の陥落、味方軍の首領の撃破、兵力0の状態でプレイヤーが倒れること、時間切れ

### 再出撃

- 倒れたプレイヤーは数秒後、兵站線につながった最寄りの味方拠点から再出撃する
- 最寄りは、倒れた位置から拠点の中心までの距離で決める。孤立した拠点と敵軍の拠点からは出ない
- 再出撃のたびに兵力を1使う
- 兵力は出撃したときに決まった数から始まり、パーティーで共有する
- 兵力が0の状態で倒れると負ける（再出撃しない）
- 戦闘の前後のイベントシーンとリザルトで倒れた人は、兵力を使わずに出撃地点から出る
- 仲間による蘇生はなし

## 軍と交戦

- 敵軍も味方軍も、首領・上忍・部隊（下忍）で構成する
- 味方軍は敵軍よりやや弱くする

### 部隊と下忍の処理

敵は部隊単位のデータで持ち、プレイヤーの近くだけ細かく動かす（[ADR 0003](adr/0003-enemies-as-squad-data-materialized-near-players.md)）。

- 戦場全体は部隊単位のデータ（位置・兵数・士気）として扱い、視界の外では位置だけを動かす
- プレイヤーの周囲に入った部隊だけ、下忍を個体として出す（実体化圏）。出現と消滅の半径に差を付ける
- 個体として細かく動かす下忍は、サーバー全体で数十体に収める
- 同時にプレイヤーを攻撃できる下忍の数を、プレイヤーごとに2〜3体に絞る（攻撃トークン）
- 実体化と消滅は、プレイヤーの視界の外で行う。消えた下忍は部隊に戻る
- 下忍の描き方（サーバーの Humanoid か、クライアントでの描画か）は、M1 の最初の試作でスマホ実機を使って比べて決める

### 方針

- 部隊ごとに、配置で方針（攻略・防衛・救援）と担当の拠点（部隊が始まる拠点）を決める。率いる上忍のいない部隊も方針で動く
- 攻略は、つながりをたどった先の、道のりが一番近い相手の拠点を目指す。相手の拠点を落としてから、その先の拠点を目指す
- 防衛は、担当の拠点に近づいた相手の部隊を迎え撃つ。近づいた相手がいなければ担当の拠点へ戻ってとどまる
- 救援は、耐久が減って攻められている味方の拠点へ向かう。向かう拠点が無ければ担当の拠点にとどまる
- 攻略で目指せる相手の拠点が無いときも、担当の拠点へ戻ってとどまる
- 部隊はつながりの道に沿って拠点から拠点へ進む。落石で塞がれた道は通らない
- 首領は本陣の範囲から出ない
- 挑発などの秘計は、方針の判断より優先して目的地を差し替えられる
- 判断の間隔と、迎え撃つ距離と、救援に向かう耐久の割合は `Config.luau` で調整する

### 交戦

- 敵味方の部隊がぶつかると、士気と兵数で押し合い、決着がつくまでその場にとどまる
- 味方軍をうまく使えば、敵の侵入を防げる
- 士気の差が十分に開いたときだけ、味方軍が自力で敵の上忍を倒せる
- 計算は、前線幅に上限を付けたランチェスター一次則に士気を掛ける形から始める。前線の後ろに控える兵も押す力に数える
- 両軍の上忍がいる部隊どうしの交戦では、上忍同士も戦う。与ダメージは攻撃と相手の防御で決め、士気の差の倍率を掛ける
- 味方軍の上忍は、部隊の士気の差がしきい値以上のときだけ敵の上忍を削れる。敵軍の上忍に士気の条件はない
- 味方軍の上忍と首領は、体力・攻撃・防御を敵軍より少し低くする

### 士気

- 軍全体の士気を1本持ち、画面上部に表示する
- 部隊ごとの士気は、軍全体の士気を基準に、近くの出来事（上忍の撃破、拠点の陥落、秘計）で上下する
- 出来事が起きると、軍全体の士気は得をした軍が上がり、相手の軍が下がる
- 出来事による部隊の士気の上下は、出来事の位置に近いほど大きく、時間がたつと元に戻る
- 率いる上忍を失った部隊は、士気が下がったままになる
- 交戦の押し合いは、部隊ごとの士気の差で決まる

## 秘計

真・三國無双6 Empires の絶招秘計に寄せる。

- 出撃前に1人3枚を選んで持ち込み、それぞれ1戦に1回使える
- 持ち込みは出撃したときに決まり、ステージが終わるまで変わらない
- 3枚より少なくても出撃できる
- 1枚も選ばずに出撃した人には、誰も選んでいない秘計を配る
- 配るのは下の表の順で、選ばなかった人へ1枚ずつ順に配る（3枚に達するか、配る秘計が無くなったら終える）
- 4人とも選ばなければ2枚ずつになる
- 同じ秘計はパーティーで1人だけが持てる
- 敵軍の上忍と首領も秘計を使う。味方軍の NPC は使わない
- 味方を巻き込む効果はない
- 資源（食料や金）は消費しない
- M1 では全種類を最初から使える。M3 で、戦い方（撃破、拠点制圧、救援など）で系統ごとの熟練度が上がり、秘計を覚える方式にする

### M1 の秘計

| 秘計 | 効果 |
|---|---|
| 伏兵 | 指定地点に味方の部隊を潜ませ、近づいた敵部隊を奇襲して士気を下げる |
| 落石 | 決められた地点の道を塞ぎ、兵站線を切る |
| 大火計 | 決められた地域の敵にまとめて大ダメージを与える |
| 兵糧庫 | 味方の拠点を改築する。兵站線が切れても孤立しない |
| 爆破罠 | 味方の拠点に仕掛け、耐久が3分の1まで減ると爆発して拠点内の敵を吹き飛ばす |
| 挑発 | 近くの敵の上忍を自分のところへ誘い出す |
| 鬼神化 | 60秒、自分の攻撃と防御が上がり、のけぞらない |
| 大喝 | 敵の強化の秘計を打ち消し、周囲の敵を30秒動揺させる |

- 発動できなかった枚（対象が無い、重ねがけなど）は使わずに残る
- 兵糧庫は、発動者が中にいる味方の通常拠点を改築する。本陣と拠点の外では使えず、すでに兵糧庫の拠点には重ねて使えない
- 兵糧庫に効果の期限はなく、拠点が制圧されるまで残る。両軍に見える目印（米俵）を拠点に置く

## 攻撃と操作

- 通常攻撃は6段。通常攻撃の段数に応じてチャージ攻撃が C1〜C6 に分岐する
- 武器の持ち替えはなし。1キャラクター1武器（[ADR 0004](adr/0004-no-weapon-switching.md)）
- EX 攻撃と天稟はなし
- 緊急回避は、ガード中に方向を入れて出す。続けて出すほど後隙が伸び、時間がたつと戻る
- 奥義はキャラクターの忍術。奥義ゲージのストックは最大4本で、1回に1本使う。M1 は1人1種
- 攻撃判定のタイミングと移動量はスクリプトと `Config.luau` で持つ。モーションを差し替えても判定は変わらない

### ボタン

| 操作 | PC | ゲームパッド |
|---|---|---|
| 通常攻撃 | 左クリック / Z | X |
| チャージ攻撃 | 右クリック / X / E | Y |
| ジャンプ | Space | A |
| ガード（方向入力で緊急回避） | Shift | L1 |
| 奥義 | Q | B |
| 秘計 | 1〜3 | 十字キー |
| イベントシーンのスキップ | F | R1 |

### ステータス

- キャラクターごとに体力・攻撃・防御・移動速度などの能力値を持つ
- M1 は成長なしで固定値。M3 で特技ツリーによる成長を足せる作りにしておく

## 画面

M1 に入れる画面。

- ミニマップ（拠点、兵站線、支配エリア、部隊、上忍、仲間の位置）
- 画面上部に軍全体の士気、残り時間、兵力

## 素材

| 素材 | 作り方 |
|---|---|
| マップ | Claude が Studio MCP で地形と和風の建物の下地を作り、開発者が仕上げる。プレースに保存し、Git では管理しない |
| 顔グラフィック | NINJAMCP の画像をもとに Codex で作る |
| BGM・効果音 | Roblox の Creator Store にある、ゲームで使ってよい素材 |
| 武器・小物 | Studio の生成 AI、Creator Store、または Meshy |
| モーション | 待機と移動は Roblox 公式の Ninja パック。攻撃・ガード・被弾・ダウンは Meshy のモーションライブラリ（fal 経由） |
| 本番のキャラクター（M2） | Meshy を fal の API 経由で使い、ややローポリで作る |

### Meshy と fal

- fal の `meshy/v7.1/*` を使う。`fal-ai/meshy/v5/*` は 2026-10-01 に非推奨
- Roblox はメッシュ1つあたり2万三角形までなので、`target_polycount` を必ず指定する
- 自動リグはテクスチャ付きのメッシュが前提
- fal はクレジットの前払い制。`FAL_KEY` は開発者が発行して設定する
- fal 経由の生成物の所有権は規約に明記がない。本番のキャラクターに使う前に fal へ確認する

### モーションの使い回し

- Meshy のリグで作ったモーションを R15 で再生する、またはその逆は、Adaptive Animation で仕様上は可能だが成功例がない
- M1 の最初に1本ずつ往復で検証する。失敗したら Blender の Rokoko Retarget で R15 に移す経路に切り替える

### 本番キャラクターの作り方（M2）

- 敵の上忍・首領やイベントシーンの NPC は、開発者が購入した記事の手順で作れる（リンクのみ記載、中身は書き写さない）
  - https://brain-market.com/u/haru_mv/a/b1ATN5QjMgoTZsNWa0JXY
- 操作キャラクターにする手順は記事にない。Adaptive Animation か Avatar Setup による R15 化を M2 の最初に検証する

## 技術方針

- ゲームロジックはサーバー権威。クライアントは入力と表示だけを担当する
- ドメイン用語の識別子はローマ字（[ADR 0005](adr/0005-romaji-identifiers-for-domain-terms.md)）
- 交戦の計算、兵站線のつながり判定、秘計のルールなど、Roblox に依存しない計算は `src/shared` に置き、Lune で単体テストする。CI にも加える
- 画面や操作の確認は、Studio MCP でのテストプレイ手順を issue に書いて行う
- キャラクターや部隊を出現させる処理は、固定の高さを使わず `src/shared/Ground.luau` の地面の高さの関数で高さを決める
- マップを触る issue はプレースを直接書き換えるので、並行させず1件ずつ進める
- 目印の置き場所・名前・タグ・Attribute は [ADR 0006](adr/0006-positions-as-markers-composition-in-code.md) に従う
- 進行の保存には DataStore を使う
