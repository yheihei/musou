# 伊賀第1ステージ「風魔襲来」

伊賀のストーリーの第1ステージの、あらすじ・登場人物・台本の下書き。
開発者が直して確定版にする（#14）。確定するまで、名前・人選・台詞はすべて案である。

- 舞台は戦乱の時代。現代のキャラクターも登場するパラレル設定（[ADR 0001](../adr/0001-setting-warring-era-clan-war.md)）
- キャラクターの設定は NINJAMCP を正とする
- 拠点の名前と配置は仮置き。伊賀第1ステージの配置図（#23）で確定する

## あらすじ

戦乱の時代、風魔が国境の峠を越えて伊賀へ攻め入った。
先陣を率いるのは風魔の首領格アトザ。弟のアウン、配下の呂屯と断が脇を固める。
峠のふもとの拠点はすでに風魔の手に落ち、伊賀の兵站線は細くなっている。

伊賀の師匠格ハヤテは里の入口の本陣で指揮を執り、相棒の鷹ナルカミの目で戦場を見渡す。
令は本陣の前の拠点を守り、餡音と紫苑は部隊を率いて前に出る。
プレイヤーは伊賀の忍として出撃し、奪われた拠点を取り返しながら峠の本陣を目指す。

首領アトザを撃破するか、峠の本陣を制圧すれば勝ち。
敗れたアトザは部下を死なせないために兵を引き、この戦は始まりにすぎないと言い残す。
峠の上の崖では、風魔の初代首領が伊賀の里を見下ろしていた。

## 敵軍の首領の案

### 第一案 アトザ

台本はこの案で書いた。

- 公式で「風魔クランを率いる首領格」「情に厚い」と設定されている
- 弟のアウン、配下の呂屯と断がそろい、敵の上忍を公式の関係だけでまとめられる
- 公式ではアトザは後に岩爺と根の国を封印する。敗れて兵を引く形にすれば、のちの共闘へつなげられる
- 風魔の初代首領を伊賀のストーリーの山場まで温存できる

### 代案 風魔の初代首領

- 公式の「刃と風魔の初代首領の死闘」を最初のステージから物語の軸に置ける
- ただし物語の山場を第1ステージで使い切る
- 首領を撃破するとクリアになるため、第1ステージで初代首領が倒されることになる
- 公式では死闘の末に刃が命を落としたとされる。第1ステージで決着させると、この設定との整理が難しい

## 風魔の初代首領（本作で作成する案）

| 項目 | 案 |
|---|---|
| 名前 | 小太郎（こたろう）。代わりの案は颪（おろし） |
| 見た目 | 背の高い壮年の男。黒と深緑の装束に、風にちぎれた長い襟巻き。顔の上半分を鬼の半面で覆い、白い長髪を後ろで束ねる |
| 忍術 | 風遁「鎌鼬（かまいたち）」。鉄扇を振るうと刃のような風が巻き、周りの兵をまとめて切り裂く |
| 武器 | 鉄扇 |
| 口調 | 低く静かで、古い言い回しを使う。怒鳴らない |

### 公式との関係

- 公式で決まっているのは、刃と風魔の初代首領が死闘を演じ、刃が命を落としたとされることだけ
- 名前・姿・忍術・武器は公式に無く、本作で決める
- 公式の未確定のメモに、風魔の首領の正体を小太郎とする説がある。名前の第一案はこれに合わせた
- 伊賀のストーリーでは、第1ステージで影だけを見せ、最後のステージで刃との死闘を描く構成を想定する
- 死闘の結末はパラレル設定として開いたままにできる。決めるのは4クランのストーリーの構図（#146）
