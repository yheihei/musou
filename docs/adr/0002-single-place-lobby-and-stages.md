# ロビーと全ステージを1つのプレースに置く

Roblox のステージ制ゲームでは、ロビー用と戦場用にプレースを分け、パーティーごとに予約サーバーへテレポートする形が多い。
本作は1つのプレースにロビーと全ステージを置き、1サーバーを1パーティーとして扱う。
テレポートは Studio 内でテストできず、一人開発の速度を優先したためである。

## Considered Options

- ロビーと戦場を別プレースに分け、予約サーバーへテレポートする。途中参加を構造的に防げるが、テストのたびに公開が要る

## Consequences

- 途中参加の禁止はプレースの分離では防げない。出撃中にサーバーへ入ったプレイヤーは、ステージが終わるまでロビーで待たせる
- 全ステージのマップが同じプレースに入る。プレースの容量と読み込み時間に注意する
