# 舞台を戦乱の時代のクラン抗争にする

CryptoNinja 公式の現代（シーズン2）は4クランが共存する平和な時代で、CryptoNinja のファウンダーが開発中の Roblox 作品「Ninja vs 1000 Oni」は忍者と鬼の戦いを描いている。
本作は無双らしい陣営同士の戦を作るため、シーズン1（戦乱の時代）を舞台にし、クラン同士の抗争として描く。
公式のシーズン1で決まっているのは「刃と風魔の初代首領の死闘」と「岩爺とアトザたちによる根の国の封印」の2つだけで、クラン同士の大戦に触れているのはアニメの前日譚のみである。
シーズン1に確実にいる公式キャラも刃・岩爺・アトザの3人だけなので、現代のキャラも登場するパラレル設定とする。

## Considered Options

- シーズン3（根の国の悪鬼と4クランの共闘）。公式の構想に沿うが、敵が妖怪になり、ファウンダーの作品と題材が重なる
- 正史寄りのシーズン1。操作キャラが足りず、大半をオリジナルの忍で埋めることになる

## Consequences

- 公式設定と食い違う描写が出る。タイトル画面などで、非公式ファンゲームかつパラレル設定であることを明記する
- 敵も人型の忍になる。下忍のモデルは人型を前提にする
- 戦乱の構図、風魔の初代首領の名前と姿、各クランの当時の首領、里の地形は公式に無く、本作で決める
