# 敵は部隊単位のデータで持ち、プレイヤーの近くだけ細かく動かす

無双らしい大軍を Roblox で動かすため、下忍を1体ずつ常に Instance として動かすのをやめる。
戦場全体は部隊単位のデータ（位置・兵数・士気）として扱い、視界の外では位置の移動だけを進める。
プレイヤーの周囲にいる下忍だけを個別に動かし、同時に細かく動くのは数十体に収める。
Humanoid 付きの下忍をサーバーで動かす現状の作りでは、通信量の都合で数十体が上限になるためである。

## Consequences

- 当たり判定、吹き飛び、撃破数、HUD は、個々の下忍ではなく部隊のデータを起点に作る
- 近くの下忍を Humanoid で動かすか、クライアント側で描くかは、初期の無双シリーズの手法を調べたうえで実測して決める
- 下忍の見た目は、部隊と個体の間を行き来しても破綻しない作りにする
